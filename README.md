# Laboratório de Azure Speech Studio e Language Studio

## 🎯 Objetivo

Este repositório contém as anotações e insights obtidos durante a prática com as ferramentas Azure Speech Studio e Language Studio. O propósito é consolidar o aprendizado no uso de inteligência artificial voltada para voz e linguagem natural.

## 🔧 Ferramentas Utilizadas

- **Azure Speech Studio**: para conversão de texto em fala (TTS), reconhecimento de fala (STT) e análise de sentimentos em transcrições.
- **Azure Language Studio**: para extração de entidades, análise de sentimentos e classificação de texto com IA.

## 🧠 O que foi feito

- Experimentos com modelos pré-treinados de conversão de texto em fala.
- Análise de sentimentos de transcrições de voz.
- Criação de projetos no Language Studio para classificar e extrair informações de textos.

## 🧪 Exemplos de Casos de Uso

- Atendimento automatizado com análise de sentimentos.
- Transcrição de reuniões com identificação de tópicos relevantes.
- Classificação automática de e-mails ou formulários usando linguagem natural.
